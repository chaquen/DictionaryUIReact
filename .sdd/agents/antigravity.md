# Adapter: Antigravity

> Las capacidades de Antigravity no están documentadas aún.
> Usa el bootstrap para que el agente se autoconfigure la primera vez.

## Primera vez en este proyecto

Pega el contenido de `.sdd/bootstrap.md` en el chat de Antigravity.
El agente responderá las preguntas de capacidades, generará su configuración,
y registrará el resultado en `.sdd/tool-config.md`.

Una vez completado el bootstrap, este archivo se actualiza con los resultados.
